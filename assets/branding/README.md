# NeuralEye Logo Package

Included:
- `NeuralEye_Logo_Saturated_Exact.svg` — self-contained SVG containing the supplied artwork with a subtle saturation boost.
- `neuraleye-logo-saturated-4x.png` — 4x PNG export.
- `index.html` + `style.css` — ready-to-open web version.
- `NeuralEyeLogo.jsx` + `NeuralEyeLogo.css` — React component.

Notes:
- The source image is 1536×392 px.
- Saturation is increased subtly (about 22%) to keep the original look while making the blue/purple gradients more vivid.
- The 4x export is an upscale of the supplied artwork; it cannot create detail that was not present in the original raster source.
- For truly infinite-resolution, pixel-perfect vector artwork, the original logo's vector source/font would be required.
